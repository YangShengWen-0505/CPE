## 使用方式

每個程式檔案對應一個線上題目。檔案名稱通常依照題目編號或題目名稱命名，方便查找與複習。

使用前請確認題目的輸入格式與輸出格式，並依照線上評測平台的編譯環境進行測試。

## 學習目標

透過持續解題熟悉 C++ 語法與標準函式庫，建立資料結構與演算法的基礎，並培養將問題轉換成程式解法的能力。
